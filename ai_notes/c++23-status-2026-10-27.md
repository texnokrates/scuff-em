## Where the workstream stands

Completed, in order:

1. Build-system migration (CMake; Autotools removed).
2. Phase 1 correctness work: dependency-free unit-test harness, libhrutil
   string/complex/token hardening, out-of-bounds / use-after-free /
   overlapping-buffer / uninitialized-state fixes, printf-format
   attributes on the varargs API.
3. Stage A: CLI11 2.7.2 vendored under `third_party/CLI11`; the hand
   written `ProcessOptions` parser replaced by a CLI11-backed adapter
   that preserves the legacy contract (case-insensitive names, stdin
   option files, repeated/multi-value options, negative and single-dash
   values, bare `--` rejection).
4. ASan/UBSan pass: two real UB fixes, remaining `-Wformat-truncation`
   warnings removed, CI sanitizer job added.
5. Stage B started: `libs/libhrutil/ScuffCLI.{h,cc}` typed helpers
   (`CollectArgs`, `Parse`, `AddComplexOption`) and the `scuff-tmatrix`
   migration with unit + smoke tests.
6. Stage B/G3 complete: **all 12 built applications migrated to typed
   CLI11 with RAII**, each verified against pre-migration binaries.
   **All developer/test programs migrated off legacy parsers.**

Remaining:

1. **Leaf-first library ownership sweeps:** libscuff geometry core last
   (`RWGSurface`/`RWGGeometry` rule-of-five, destructor-leak cleanup),
   libhmat rule-of-five + LAPACK workspaces → `vector<T>`, libMatProp/
   libSubstrate/libMDInterp ownership cleanup, libscuff caches (kill
   `void*` erasure, unify on `std::shared_mutex`, fix FIPPICache key
   leak).
2. **G4 ratchet:** clang-tidy warnings-as-errors blocking-for-changed-
   files; warning-budget enforcement continues per master plan.
3. Phase 4 language/style backlog (master plan Section 6): remove
   `using namespace std` from `libhrutil.h`, drop TR1/`HAVE_CXX11`
   branches, `std::string`/`string_view`/`filesystem` helpers,
   `thread_local` buffers.  (The C-style *string* API wrappers
   (`RemoveDirectories` &c.) intentionally stay per plan decision 7 —
   removal is a separate documented release decision, distinct from the
   parser removal completed here.)

Separate known backlog (do not block CLI work):

- ~74 MB exit leak from long-lived application objects (geometry,
  material, cache); a dedicated RAII/ownership pass, recorded in
  `ai_notes/c++23-sanitizers-2026-10-26.md`.
- TSan CI job once the static-buffer fixes land (CD2S and friends are
  already `thread_local`; the remaining global state audit is open).
- The dormant `scuff-cas2D`/`scuff-microstrip` trees stay unbuilt and out

## Conventions for this workstream

- Record findings, plans, and results as dated markdown files in
  `ai_notes/`; update the status/"Remaining work" sections of existing
  notes as work lands instead of letting them go stale.  **Commit note
  changes in the established `[ai_notes]` style.**
- Small, reviewable commits in the established `[area] summary` style
  (e.g. `[libhrutil] ...`, `[scuff-tmatrix] ...`,
  `[ai_notes] ...`).  Build and CTest must be green per commit.
- Numerical kernels stay byte-for-byte; modernization happens at the
  edges (CLI, strings, ownership, diagnostics) unless fixing a specific
  confirmed defect.
- Do not hand-edit generated code (f2c output, cmatheval parser/scanner,
  quadrature tables) beyond targeted UB fixes.
- `clangd-22` is available for navigation and diagnostics;
  `clang-tidy-22` for Core Guidelines diagnostics.

## Core Guidelines mandate (added 2026-10-27)

The user's mandate now also covers mapping violations of the ISO C++ Core
Guidelines and deciding per module between C++23-with-guidelines refactors
(including pointer-ownership conventions: `unique_ptr` default,
`gsl::owner` annotations, `span`) and plain-C conversion for effectively-C
sources.  Findings, per-module dispositions, the defect list (G-01..G-27),
and the phased plan live in
`ai_notes/core-guidelines-survey-2026-10-27.md`.  Headline verdicts:
plain-C candidates are the libTriInt cubature quartet and libMDInterp's
BinSearch/freadEC; everything else refactors as C++23; no application can
be plain C (they all construct C++ library objects); 21 new live/latent
defects were found and are queued ahead of ownership refactoring.
